mac-cron-manager

A dashboard for the cron jobs and launchd agents on your Mac.
Looking for the agent on this Mac…

The dashboard runs on your Mac, served by a small agent at . Nothing leaves your machine; this page only checks whether the agent is there and takes you to it.

  1. Install the agent (macOS, Python 3.10+). It starts at login from then on: 
    git clone https://github.com/induction-axiom/mac-cron-manager ~/mac-cron-manager && ~/mac-cron-manager/install.sh
  2. Come back here. If the browser asks whether this site may access devices on your local network, choose Allow: that's how it finds the agent. Or skip this page and open directly.
  3. Installed before but not responding? Restart it: 
    launchctl kickstart -k gui/$(id -u)/local.mac-cron-manager

Source and docs: github.com/induction-axiom/mac-cron-manager
