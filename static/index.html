This page is only the interface. A small agent on your Mac reads the crontab and launchd jobs; the page talks to it over 127.0.0.1 and nothing leaves your machine.

  1. Install the agent (macOS, Python 3.10+). It starts at login from then on: git clone https://github.com/induction-axiom/mac-cron-manager ~/mac-cron-manager && ~/mac-cron-manager/install.sh
  2. When Chrome asks whether this site may access apps and services on your device, choose Allow.
  3. Already installed but stopped? Restart it: launchctl kickstart -k gui/$(id -u)/local.mac-cron-manager

Prefer not to use a hosted page? Open http://127.0.0.1:7878 once the agent runs: it serves this same dashboard, with editing enabled.
